# Bento Command catalogue

The catalogue is maintainer-only review tooling. It is not copied into plugins
generated by the kit. It presents the final Bento Command layout with the
Structured treatment across six surface studies, their task states, all built-in
themes, and the fixed review viewport matrix.

Run the live review at the terminal's delivered size:

```sh
go run ./cmd/catalogue
```

Static evidence is optional and supports theme, viewport, and scenario filters:

```sh
go run ./cmd/catalogue --output /tmp/catalogue --theme nord --viewport phone-keyboard --scenario error
```

The static matrix contains `40x10`, `48x18`, `48x30`, `78x10`, `78x20`,
`80x18`, `110x24`, and `500x200` for every built-in theme and scenario. PNGs,
contact sheets, and the HTML/JSON index are export-only review evidence.

## Controls

| Key | Result |
| --- | --- |
| `p` / `P` | Next / previous surface |
| `s` / `S` | Next / previous state |
| `t` / `T` | Next / previous built-in theme |
| `Tab`, `Left`, `Right` | Select and change surface, state, or theme |
| `h` | Toggle geometry and resize HUD |
| `?` | Open or close help |
| `/` | Clear and edit the sample query |
| `Enter` | Commit an edit or advance the task flow |
| `Backspace` | Delete one grapheme while editing; otherwise go back one state |
| `Up` / `Down` | Move the visibly marked selection |
| `Esc` | Leave editing, then quit |
| `q`, `Ctrl-C` | Quit |

The live terminal uses its actual delivered geometry. The fixed matrix is for
one-to-one pane review: resize the Herdr pane to the labelled cells and confirm
the HUD reports the same size. The HUD and semantic diagnostics retain geometry,
focus, surface, state, theme, and selection without recording the query.

At 18 or fewer rows, Bento Command keeps the title and editor visible while
dedicating remaining rows to the task. The compact footer points to `?` and the
help view lists its controls directly. The catalogue is review tooling; its
surface studies are mocks, not future plugin implementations.

Record the approved Bento Command / Structured behavior, theme policy, and
real-device observations in `docs/ui-contract.md` once the user approves it.
